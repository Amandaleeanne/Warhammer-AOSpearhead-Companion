Explaination of this file folder:

Since we are using Drift instead of SQflite, some additioanal steps have to be made.

First, the database files are already located inside databases/
Second, the spearhead_database.dart contains all of the dart code needed to setup and manipulate the database we are selecting (in this case I am using the spearhead DB as an example). Then, tables.drift uses raw SQL to generate the spearhead_database.g.dart as the autogenerated code using ``dart run build_runner build``

Finally, compiledSpearhead contains all of the Models needed to make a cached spearhead. This allows me to have the user make selections, query the DB once and then just have a working class for easy getting and setting completely and cleanly seperate from the database. Yes, I should make them seperate files but I don't want to.
