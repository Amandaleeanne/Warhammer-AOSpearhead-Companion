# Warhammer AOS Spearhead Companion

# Summary:
This is a Flutter + SQLite application developed as a capstone project for my SDE Bachelors class.
At its core, it provides an better, in my opinion, UI flow than the current offical warhammer AOS applciation;
as well as some QOLs that I wish the offical application has. 

This is in no way affiliated with the people who made Warhammer, it is simply a pasion project and all rights go to them.

# Current Phase:
If you are seeing this page before the application is complete, hello, but also this is still before the MVP (Minimum viable product) is complete.
The UI and Functionality are not finished one bit, and I am still learning flutter and dart. This repo is here so that my teacher has acsess and can see updates.
I plan on a complete polish after my class is over on June 16th, but the goal is to have main functionality complete by then.
